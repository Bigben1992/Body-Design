## Как обновить сайт
1. Открой тот же GitHub-репозиторий, который подключён к Netlify.
2. Нажми **Add file → Upload files**.
3. Загрузи все файлы из архива в корень репозитория с заменой старых.
4. Нажми **Commit changes**.
5. Netlify автоматически обновит сайт по той же ссылке.

Если URL Netlify не меняется, уже сохранённая история тренировок остаётся в localStorage на этом домене.
