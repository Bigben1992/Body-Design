# Paulina Best Ass Workout v7

Что изменено:
- превью упражнений теперь показываются в режиме **clean photo**:
  изображение слегка увеличено и смещено вверх, чтобы убрать слова/текст,
  которые часто находятся в нижней части превью;
- заголовок сохранён как **Paulina Best Ass Workout 🍑**;
- русские названия упражнений и точное первое видео сохранены;
- обновлены versioned JS и PWA cache, чтобы Safari/Netlify точно подхватили новую версию.

Как обновить:
1. Загрузить все файлы из архива в тот же GitHub-репозиторий с заменой старых.
2. Сделать Commit.
3. Открыть сайт в Safari и обновить страницу.
4. Полностью закрыть PWA и открыть заново.
