Как опубликовать:
1. Распакуйте архив.
2. Загрузите **все файлы** в корень того же GitHub-репозитория, подключённого к Netlify, и сделайте Commit.
3. После успешного деплоя откройте сайт в Safari, обновите страницу и перезапустите PWA.

Важное: сохранённые данные тренировок лежат локально на устройстве. Адрес Netlify и ключ localStorage не менялись. На всякий случай до обновления можно сделать экспорт из раздела «История».
