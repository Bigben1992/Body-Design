# Paulina Best Ass Workout v23 🍑

## Новая шапка для iPhone и Dynamic Island

- Единый премиальный тёмно-синий фон `#101322` во всей верхней зоне: под Dynamic Island, за названием и за навигацией.
- Шапка с градиентным названием, подсветкой активной кнопки и тонкой розово-фиолетово-бирюзовой линией.
- Шапка и кнопки «Тренировки / История / Прогресс» теперь `position: fixed`, а не `sticky`: не съезжают вниз при прокрутке в iOS Safari/PWA.
- Высота шапки автоматически измеряется, чтобы не закрывать упражнения и корректно учитывать безопасную область экрана.
- `theme-color` и цвета PWA согласованы с верхней зоной, одинаковы при светлой и тёмной теме, чтобы Dynamic Island не выделялся чужим фоном.
- Добавлен `_headers` для корректного обновления файлов сайта в Netlify.
- Обновлены версия скриптов и Service Worker до v23.

## Без изменений

Тренировки, пресс (день 1: планка, день 2: обратные скручивания, день 3: классические скручивания), фотографии, видео, подробная техника, журнал весов, история и прогресс. Ключ localStorage `bodyDesignLogsV2` не менялся.

## Публикация

Распаковать ZIP и загрузить **все файлы, включая `_headers`**, в корень прежнего GitHub-репозитория, связанного с Netlify, затем Commit. При обновлении сайта по прежнему адресу история сохраняется, если не удалять данные Safari. Перед изменением можно экспортировать историю через «История → Скачать JSON».

### Проверка

Под названием сайта должна появиться `v23`. Если там v22, то на устройстве открылась старая копия (или ещё не завершился Netlify deploy).
