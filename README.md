## Как установить обновление

1. Распаковать ZIP.
2. В прежнем GitHub-репозитории: Add file → Upload files.
3. Загрузить все файлы с заменой старых, затем Commit changes.
4. Дождаться Deploy на Netlify. Открыть сайт в Safari и обновить.

История тренировок сохраняется, если адрес сайта и данные Safari не меняются. На всякий случай перед обновлением можно сделать JSON-экспорт из раздела «История».
