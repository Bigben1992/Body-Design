Полный пакет для существующего сайта GitHub → Netlify. Содержит обновлённые HTML, JavaScript, manifest, Service Worker, изображения упражнений и выбранную иконку с персиком (вариант B).

- Прежняя история румынской тяги по-прежнему называется «Румынская тяга»; новое упражнение получает отдельный ID и статистику.
- Остальные упражнения, рабочие веса, трекер подходов, история, графики, таймер, темы, верхняя навигация и выбранная иконка iPhone не изменены.

## Публикация
1. Распакуйте ZIP.
2. Загрузите **содержимое** папки, включая `_headers`, в корень прежнего GitHub-репозитория. Замените одноимённые файлы.
3. Сделайте Commit changes. Netlify обновит сайт автоматически.
4. Убедитесь, что рядом с названием появилась метка **(v27)**. На iPhone возможно кэширование прежней версии: откройте сайт в Safari, проверьте актуальный Netlify Deploy и обновите страницу.

Данные хранятся локально в браузере (`bodyDesignLogsV2`). При прежнем адресе сайта история сохраняется; перед обновлением рекомендуется экспортировать резервную копию. Не удаляйте данные Safari.
