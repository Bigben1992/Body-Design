# Body Design Workout PWA

Персональная веб-версия тренировок для iPhone.

## Что умеет
- 3 готовые тренировки
- техника каждого упражнения
- ссылка на видео техники
- ввод веса, повторений и RIR по каждому подходу
- дата и заметки
- история тренировок
- предыдущий результат прямо в карточке упражнения
- график прогресса
- экспорт/импорт данных в JSON
- после первого открытия работает офлайн как PWA

## Лучший способ открыть на iPhone
Разместить папку на GitHub Pages или другом HTTPS-хостинге, затем:
Safari → Share → Add to Home Screen.

Данные сохраняются в localStorage конкретного iPhone. Чтобы не потерять историю, периодически делайте Export.
