## Обновление сайта
1. Распакуйте ZIP.
2. Загрузите **все файлы** в корень того же GitHub-репозитория, подключенного к Netlify, с заменой старых файлов.
3. Сделайте Commit. Netlify автоматически развернёт обновление.
4. Откройте приложение в Safari и перезапустите его при необходимости.

Данные тренировок хранятся локально на устройстве: не меняйте адрес сайта и не очищайте данные Safari. Перед обновлением можно сделать экспорт из раздела «История».
