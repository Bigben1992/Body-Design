## Обновление сайта
1. Распакуйте архив.
2. Загрузите все файлы в корень **того же** GitHub-репозитория, связанного с Netlify.
3. Сделайте Commit. Netlify автоматически развернёт обновление.
4. Не меняйте адрес сайта и не удаляйте данные Safari. Перед обновлением рекомендуем экспортировать историю тренировок.
