# Paulina Best Ass Workout v21 🍑

## Исправления

1. Кнопка **«🏋️ Тренировки»** в нижней навигации плавно прокручивает страницу к началу, где расположены вкладки **«Тренировка 1 / 2 / 3»**, даже если она уже активна. При повторном нажатии на активную вкладку поля весов, повторений и RIR **не сбрасываются**.
2. Проверена программа для пресса (три разных упражнения, каждое в конце своего дня):
   - День 1, №6: **Планка на предплечьях**, 3 × 30–45 секунд.
   - День 2, №7: **Обратные скручивания на скамье**, 3 × 10–15.
   - День 3, №8: **Классические скручивания на скамье**, 3 × 12–15.
   Все три карточки с нужными фотографиями, техникой и роликами уже имелись в v20. Ошибочные два варианта планки в v21 не допускаются.
3. Нижнее меню в браузере поднято на 58 пикселей над внешними виджетами, например «Powered by Netlify», чтобы **«История»** оставалась доступна для нажатия. В установленной PWA на домашнем экране меню, как раньше, прижато к низу.
4. PWA-кэш, версии скриптов обновлены до **v21**; возле заголовка теперь показан номер версии, чтобы можно было проверить обновление после деплоя.

## Что сохранилось

Состав и порядок остальных упражнений, техника, фото, видеоролики, история, статистика и логика рабочих весов. Ключ истории `bodyDesignLogsV2` и идентификаторы текущих упражнений не изменялись. Старые записи планки дня 3 (`plank_3`) по-прежнему отображаются в истории под старым названием.

## Публикация в GitHub → Netlify

1. Распакуйте ZIP и загрузите **содержимое папки** в корень того же репозитория, связанного с Netlify; согласитесь на замену файлов и Commit.
2. Проверьте на сайте мелкую метку **v21** под названием. Если видна старая версия, значит Netlify ещё не обновил деплой, старые файлы не заменились в GitHub или Safari показывает старую копию. Перезагрузите страницу после завершения деплоя. Не очищайте данные Safari, если не экспортировали историю.
3. Перед обновлением полезно экспортировать журнал через **История → Скачать JSON**.
