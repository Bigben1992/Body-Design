# Paulina Best Ass Workout 🍑 | v9

## Что изменилось
- Удалены надписи/бейджи поверх превью упражнений и затемняющий градиент.
- Превью отделены от обучающих YouTube-видео: больше не используются YouTube-миниатюры с напечатанным текстом. Вместо них поставлены отдельные фотографии девушек, выполняющих соответствующие упражнения; для двух вариантов ягодичного моста использовано присланное пользователем фото.
- Фото показываются без растягивания и искусственного увеличения; заголовки упражнений остаются ниже фото.
- Если внешний источник фото недоступен, показывается нейтральная заглушка без надписей.
- Исправлены переполнения по горизонтали: шапка и переключатель темы, дата тренировки, поля веса/повторов/RIR, видео-кнопки, таймер, история и графики.
- Вкладки тренировок могут прокручиваться горизонтально *внутри своей строки*, но сама страница должна оставаться неподвижной по ширине.
- Русские упражнения, YouTube-ссылки, история, прогресс и тёмная/светлая тема не менялись.
- Service Worker обновлён до v9, чтобы Safari не показывал старую версию.

## Обновление Netlify
1. Открой тот же GitHub-репозиторий, подключённый к Netlify.
2. Выбери Add file → Upload files.
3. Перетащи все 9 файлов из архива (в корень репозитория) с заменой старых.
4. Нажми Commit changes. Netlify развернёт новую версию автоматически.
5. После публикации открой сайт в Safari, обнови и перезапусти иконку на домашнем экране.

## Важно
- Локальная история тренировок сохраняется при обновлении по тому же домену. На всякий случай сделай JSON-экспорт до обновления.
- Фотографии (кроме локального ягодичного моста) пока загружаются с внешних сайтов. Из-за ограничений доступа/изменений ссылок отдельные фото могут перестать загружаться. В этом случае будет картинка-заглушка без текста. Для максимальной надёжности картинки можно разместить локально при наличии соответствующих лицензий.
