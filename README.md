## Как обновить существующую GitHub Pages

Замените файлы в том же репозитории файлами из этого архива. Важно сохранить тот же URL репозитория/Pages: тогда localStorage и история тренировок остаются на том же origin.

Перед обновлением рекомендуется открыть старую версию → История → Экспорт и сохранить резервную копию.
