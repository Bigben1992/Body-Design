# Paulina Best Ass Workout v22 🍑

## Изменения относительно v21

- Меню «🏋️ Тренировки / 🗓 История / 📈 Прогресс» закреплено **сверху**, непосредственно под названием. Оно остаётся на экране при прокрутке.
- Нижняя навигация убрана, бейдж «Powered by Netlify» не мешает нажимать на меню.
- «Тренировки» по-прежнему плавно прокручивает к выбору дня 1 / 2 / 3, не сбрасывая текущие незаписанные значения (при открытом разделе тренировок).
- Таймер отдыха оставлен в нижней части экрана; обновлены PWA-кэш и версия скриптов до v22.

## Без изменений

Все три программы, фото, упражнения для пресса (день 1 планка, день 2 обратные скручивания, день 3 классические скручивания), техника, видео, веса и история. Ключ истории `bodyDesignLogsV2` не менялся.

## Обновление

Распакуйте архив в корень того же GitHub-репозитория, связанного с Netlify, замените файлы, сделайте Commit. Не очищайте данные Safari; перед обновлением рекомендуется экспортировать резервную копию истории.
