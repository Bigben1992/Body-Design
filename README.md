## Как обновить
1. Экспортируй историю тренировок на телефоне в качестве резервной копии.
2. Распакуй архив. В GitHub-репозитории, связанном с Netlify, загрузи **содержимое** папки в корень (`Add file → Upload files`) с заменой файлов.
3. Нажми `Commit changes` и дождись успешной публикации на Netlify.
4. Открой **ту же** ссылку на iPhone, обнови её в Safari; при необходимости полностью перезапусти PWA. Не очищай данные Safari, чтобы история осталась на устройстве.

История хранится локально на каждом устройстве (`localStorage`); само обновление файлов её не удаляет.
