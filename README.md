# Paulina Best Ass Workout v24 🍑

Обновление интерфейса на базе v23.

## Изменения
- Убрана лишняя строка с 🎬 и пометками «Русский / демонстрирует девушка» под **каждым** упражнением. Кнопки «Смотреть технику» и YouTube остаются.
- Из информационного блока в начале тренировки удалено предложение «Фото подобраны отдельно: ...». Полезные указания про RIR и таймер остались.
- Версия обновлена до v24, включая Service Worker, чтобы iPhone получил новые файлы.

## Установка
Распакуйте ZIP в корень существующего GitHub-репозитория и выполните Commit changes. Подключённый Netlify задеплоит обновление автоматически. Вверху после публикации должна отображаться метка v24.

История хранится локально в Safari; при прежнем адресе сайта она не должна пропасть. Перед обновлением рекомендуется сделать экспорт истории.
